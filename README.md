Nome do projeto 
## O GRANDE DIA

#### Descrição do projeto
um projeto criado para ser um convite online.
o site possui informações sobre os noivos e informações do local.

---
#### Objetivo
O Projeto O Grande dia tem o intuito de ser um convite on-line para confirmar a presença de convidados para um casamento.

---
#### Publico Alvo
Para o público destinados a realizar um convite de casamento de forma online e prática.

---
#### Tecnologias utilizadas 
- HTML5 — utilizado para criar a estrutura da página.
- CSS3 — utilizado para personalizar cores, fontes e espaçamentos.
- Bootstrap — utilizado para criar o menu, botões e melhorar a responsividade.

---
#### Estrutura do site
O site possui:

- Head: Onde contém Link para o style.css, além de fontes e link JS do Bootstrap.
- Barra de pesquisa: Direcionando para partes específicas do site.
- Chamada: Onde contém frase para foco do público, e botões com a data do evento que muda de cor.
- text*img: Texto com a foto ao lado direito.
- img*text: Imagem com o texto ao lado da Direita
- carossel: Um carrossel com imagens.
- Brides: 3 Cards com diferentes itens e botões
- chamada: confirmação de presença
- Rodapé: mais informações
